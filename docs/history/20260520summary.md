## 二、打包链路修复（7 个阻塞问题）

### 1. WeasyPrint → xhtml2pdf

**问题**: WeasyPrint 需要 Pango/Cairo/GObject 原生 C 库，Windows 上无法打包。

**修复**:
- `backend/app/api/reports.py`: 替换 `weasyprint` 为 `xhtml2pdf`（纯 Python）
- 注册 ReportLab 内置 CID 字体 `STSong-Light` 解决中文渲染
- CSS 适配 xhtml2pdf 限制（不支持 `border-collapse`、`border-radius`、`max-width`）
- `backend/requirements.txt`: `weasyprint>=60.0` → `xhtml2pdf>=0.2.11`

### 2. hiddenimports → collect_all

**问题**: `hiddenimports` 只告诉 PyInstaller 找到顶层模块，不收集子模块和数据文件。`bleach` 有 43 个子模块 + 12 个数据文件，`reportlab` 有 159 个子模块 + 32 个数据文件。

**修复**:
- `scripts/build.spec`: 对 13 个关键包使用 `collect_all()` 替代 `hiddenimports`
  - bleach, reportlab, pydantic_settings, httpx, aiosqlite, xhtml2pdf, rapidocr_onnxruntime, markdown, pymupdf, mammoth, lxml, numpy, onnxruntime

### 3. RapidOCR ONNX 模型打包

**问题**: `hiddenimports` 只收集 Python 代码，RapidOCR 的 3 个 ONNX 模型文件（~16MB）+ config.yaml 未打包。

**修复**: 通过 `collect_all('rapidocr_onnxruntime')` 自动收集数据文件。

### 4. MODEL_DIR 指向只读目录

**问题**: frozen 模式下 `RESOURCE_BASE / "model"` = `_internal/model/`（只读，不存在）。

**修复**:
- `backend/app/core/paths.py`: `MODEL_DIR` 默认改为 `APP_DIR / "model"`（可写）
- `scripts/download_model.py`: 检测 `sys.frozen` 使用 exe 目录

### 5. 统一路径解析模块

**问题**: 10+ 个文件各自用 `__file__` 计算路径，frozen 模式下全部失效。

**修复**: 新建 `backend/app/core/paths.py`，统一定义：
- `BUNDLE_DIR`（只读，`sys._MEIPASS`）
- `APP_DIR`（可写，exe 目录）
- `RESOURCE_BASE`（资源查找基准）
- 所有派生路径：`DATA_DIR`、`DB_DIR`、`LOG_DIR`、`REPORTS_DIR`、`KG_INPUT_DIR`、`ENV_FILE` 等

### 6. 可写数据目录

**问题**: 数据文件写入 `_internal/data/`（只读打包目录）。

**修复**: 所有运行时数据路径（数据库、日志、报告、文档）统一使用 `APP_DIR/data/`。

### 7. 其他修复

| 问题 | 修复 |
|------|------|
| `asyncio.Lock()` 在 import 时创建 | `lightrag_tool.py` 改为懒加载 |
| `.env` 在只读目录 | 改为 `APP_DIR/config/.env` |
| `os.getenv()` 首次启动读不到值 | `startup()` 中添加 `load_dotenv()` |
| Agent prompt 文件路径 | 使用 `AGENT_DIR` + `__file__` 回退 |
| Agent frozen import 失败 | `agent_helpers.py` 使用 `BUNDLE_DIR` 修正 `sys.path` |

## 三、新功能：Tkinter GUI 启动器

### 设计目标

面向无代码基础的用户，双击 exe 后弹出 GUI 窗口引导配置，无需手动编辑 `.env` 文件。

### 实现

**新文件**: `backend/app/tkinter_launcher.py`（~300 行）

**架构原则**: 独立模块，不 import 任何 `app.*` 代码，避免循环依赖和加载延迟。

**功能**:
- 8 个 LLM 供应商选择（默认 Mimo 推荐）
- API Key 密码输入框
- 连接测试（`urllib.request`，15s 超时）
- 嵌入模型下载（modelscope，后台线程 + 不确定进度条）
- .env 文件直接读写
- 线程安全 UI 更新（`root.after()`）

**集成**: `backend/app/launcher.py` 在 uvicorn 启动前调用启动器，新增 `--no-launcher` 参数。

### 用户流程

```
双击 AuditBee.exe → tkinter 启动器 → 选供应商 + 填 Key → 测试连接 → (可选)下载模型 → 启动 → 浏览器自动打开
```
