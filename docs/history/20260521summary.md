## 二、Agent 链路修复（5 个 bug）

### 1. asyncio.Lock 竞态条件

**问题**: `lightrag_tool.py` 在 `get_lightrag()` 函数内懒创建 `asyncio.Lock()`，两个并发协程各自创建独立锁，失去互斥保护。

**修复**: 将 `_lightrag_lock = asyncio.Lock()` 移至模块级（第 103 行），全局唯一实例。

**文件**: `agent/tools/lightrag_tool.py`

### 2. risk_assessor 静默失败

**问题**: LLM 调用失败时返回 `risk_assessed=True, status="running"`，supervisor 误认为风险评估成功，继续用空数据执行后续流程。

**修复**: 失败时返回 `risk_assessed=False, status="error"`，supervisor 可正确检测并终止 pipeline。

```python
# BEFORE (静默失败):
"risk_assessed": True, "status": "running"

# AFTER (正确报错):
"risk_assessed": False, "status": "error"
```

**文件**: `agent/agents/risk_assessor.py`

### 3. supervisor error detection 扩展

**问题**: 错误检测条件为 `status=="error" and not regulation_checked`，仅在 regulation 检查前的错误能被捕获，后续阶段的错误被忽略。

**修复**: 简化为 `status=="error"`，任何阶段的错误都会终止 pipeline。

```python
# BEFORE:
if state.get("status") == "error" and not state.get("regulation_checked"):

# AFTER:
if state.get("status") == "error":
```

**文件**: `agent/agents/supervisor.py`

### 4. 死代码清理

**问题**: `risk_matrix.py` 中 `format_risk_summary()` 函数从未被调用。

**修复**: 删除该函数（-37 行）。

**文件**: `agent/tools/risk_matrix.py`

## 三、打包链路修复（3 个 bug）

### 1. LightRAG 传递依赖打包

**问题**: `build.spec` 中 `collect_all('lightrag')` 只收集 lightrag 自身代码，其传递依赖（nano_vectordb、aiohttp 等）未打包，导致 exe 中 LightRAG 初始化失败。

**修复**: 在 `collect_all` 列表中新增 7 个包：

```python
'nano_vectordb',    # LightRAG 向量存储后端
'aiohttp',          # 异步 HTTP 依赖
'networkx',         # 图操作
'pandas',           # 数据处理
'pypinyin',         # 中文拼音处理
'tenacity',         # 重试逻辑
'xlsxwriter',       # Excel 导出
```

**文件**: `scripts/build.spec`

### 2. 预构建知识图谱索引打包 + 首次运行 seeding

**问题**: 用户首次启动 exe 时知识图谱为空，需要手动重建索引（耗时长、需要 LLM API）。

**修复**:
- `build.spec`: 将 `graphrag_index/lightrag_output` 加入 datas 打包
- `build_exe.bat`: 步骤 6/7 手动 xcopy 备份
- `main.py`: startup 中检测 `KG_OUTPUT_DIR` 为空时从 bundle 复制预构建索引

```python
# main.py startup 逻辑
if paths._KG_OUTPUT_BUNDLED.is_dir():
    existing = list(paths.KG_OUTPUT_DIR.glob("*.json")) + list(paths.KG_OUTPUT_DIR.glob("*.graphml"))
    if not existing:
        for f in paths._KG_OUTPUT_BUNDLED.iterdir():
            if f.is_file():
                shutil.copy2(f, paths.KG_OUTPUT_DIR / f.name)
```

**文件**: `scripts/build.spec`, `scripts/build_exe.bat`, `backend/app/main.py`

### 3. @app.get("/") 路由冲突（前端无法显示）

**问题**: `main.py` 中 `@app.get("/")` 路由优先级高于 `app.mount("/", StaticFiles(...))`，浏览器访问根路径返回 JSON `{"message": "AuditBee API"}` 而非前端页面。

**修复**: 删除 `@app.get("/")` 路由，让 `StaticFiles(html=True)` 接管根路径。

**文件**: `backend/app/main.py`

## 四、启动器修复

### tkinter pady 重复关键字参数闪退

**问题**: `tkinter_launcher.py` 第 357 行：
```python
).pack(**pad, anchor="w", pady=(15, 0))
# 其中 pad = {"padx": 20, "pady": (0, 0)}
```
`**pad` 展开提供 `pady=(0, 0)`，显式 `pady=(15, 0)` 冲突，抛出 `TypeError: got multiple values for keyword argument 'pady'`，exe 启动后立即闪退。

**修复**: 改为显式参数：
```python
).pack(padx=20, anchor="w", pady=(15, 0))
```

**文件**: `backend/app/tkinter_launcher.py`
